# QC Checklist — AQL 2.5 Standard

## Inspection Level
- **General Inspection Level**: II (ISO 2859-1)
- **AQL**: 2.5 for major defects, 4.0 for minor defects
- **Sampling**: Single sampling plan

## Defect Classification

### Major Defects (AQL 2.5)
| Defect | Description | Action |
|--------|-------------|--------|
| M01 | Broken needle fragment in garment | **Reject lot**, metal detector recalibration |
| M02 | Wrong fabric / color vs. PO | **Reject lot**, isolate batch |
| M03 | Missing size label | **100% sort**, re-label |
| M04 | Hole or tear >5 mm | **Reject piece**, repair if possible |
| M05 | Incorrect measurements > tolerance | **Reject piece**, measurement audit |
| M06 | Oil stain >2 cm² | **Reject piece**, oil source investigation |

### Minor Defects (AQL 4.0)
| Defect | Description | Action |
|--------|-------------|--------|
| m01 | Loose thread >2 cm | Trim, accept |
| m02 | Slight shade variation within lot | Accept if within 4-step grey scale |
| m03 | Label skew >3 mm | Accept if legible |
| m04 | Minor press mark | Accept if fades after 1 wash |
| m05 | Packaging crease | Accept, note on report |

## Inspection Environment
- Lighting: D65 standard daylight, 1000–1200 lux
- Temperature: 20–24 °C
- Humidity: 55–65% RH
- Surface: Neutral grey inspection table

## Documentation
- Record lot number, PO, style, color, size breakdown
- Photo all major defects and 10% of minor defects
- Final report: Pass / Fail / Conditional Pass with conditions
- Retain records for 3 years
