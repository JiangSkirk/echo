# ADR 0004: Layered memory + Friends L1/L2 — deferred

## Status

Deferred behind AppShell Phase B/C and iPhone Companion v1.

## Decision

- Layered Entity/Claim/Episode/Revision memory and reversible compression remain
  design-only until Personal/Work AppShell isolation is production-candidate.
- Friends / A2A starts at L1/L2 only, with a protocol distinct from iPhone Host
  pairing QR. Public discovery and L3/L4 require external security review.
